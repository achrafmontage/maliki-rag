# النصوص الخام
ضع هنا ملفات الكتب بالأسماء الواردة في `data/books.csv` (عمود file).

الصيغ المدعومة (عمود format):
- `openiti`: ملفات OpenITI بصيغة mARkdown (عناوين `### |`، فقرات `# `، علامات `PageV01P012`).
- `md`: نص عادي، العناوين بـ `##` (مستوى أول) و`###` (ثانٍ)، وعلامة الصفحة `[ص: 12]`.

أنواع الكتب (عمود kind): `matn` متن، `sharh` شرح، `hashiya` حاشية، `asl` أصل (كالمدونة).
تأكد من ترخيص كل نص قبل أي نشر عام.
