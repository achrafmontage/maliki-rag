# maliki-rag — نظام استرجاع صارم للفقه المالكي

يجيب **من الكتب المدخلة فقط**، مع إحالة (كتاب/جزء/صفحة/باب) واقتباس حرفي، ويقول «لم أجد نصاً مطابقاً» حين لا يجد.
**ليس نظام فتوى.**

## كيف يمنع خطأ «المسألة القريبة»؟
1. **قاضٍ منفصل** يحدد «المسألة التي يعالجها المقطع فعلاً» ويصنفه: `exact` / `related` / `none`.
2. التصنيف يُؤخذ **من القاضي لا من النموذج المجيب**، فلا يمكن ترقية نص مجاور إلى جواب.
3. **تحقق حرفي**: كل اقتباس يجب أن يوجد في المقطع (بعد التطبيع)، وتُرفض الاقتباسات المبتورة قبل أداة نفي (لا/ليس/غير/إلا).
4. عرض النص الكامل للمقطع والمتن المشروح مع كل جواب، ووسم `related` بعبارة «مسألة مجاورة».

## المسار
`ingest` (تحليل الهيكل + تقطيع + ربط «قوله» بالمتن) ← `index` (BM25 + bge-m3) ← بحث هجين RRF ← reranker ← قاضٍ ← توليد مقيَّد ← تحقق.
قبل البحث: معجم المرادفات (`data/glossary.csv`) + توسيع الاستعلام بالنموذج + توجيه الباب.

## البدء
```bash
pip install -r requirements.txt && pip install -e .
export ANTHROPIC_API_KEY=...
# ضع الكتب في data/raw واضبط data/books.csv
python -m maliki_rag.cli ingest
python -m maliki_rag.cli index          # يُفضَّل على GPU (Colab)
python -m maliki_rag.cli ask "سؤالك"
python app/app.py                        # واجهة Gradio
python -m maliki_rag.cli eval --full     # التقييم
```
على Colab افتح `notebooks/colab_quickstart.ipynb`.

## ما عليك فعله (ليس آلياً)
- **راجع التقطيع بعينك** على عينة من كل كتاب؛ صيغ العناوين تختلف بين الطبعات، وقد تحتاج تعديل `parse_book`/`RE_QAWLUH` في `ingest.py`.
- **املأ `eval/gold_questions.jsonl`** بأسئلة حقيقية ومواضع صحيحة تتحقق منها، وابدأ بحالة الحزام. كل تعديل ← أعد التقييم.
- **وسّع `data/glossary.csv`** (عامي ← ألفاظ الفقهاء) وراجع الصفوف الأولى فهي بذور فقط.
- سجل الأسئلة في `logs/queries.jsonl` فيه حقل `reviewer_correction` لتصحيحاتك.
- تحقق من ترخيص النصوص قبل أي نشر عام (المستودع يتجاهل `data/raw` في git).

## حدود معروفة
- ربط الشرح بالمتن تقريبي (تشابه نصي بحد 85) وغير مضمون في كل المواضع.
- التقطيع يعتمد على علامات الجمل و«قوله»، وقد يحتاج ضبطاً لكل كتاب.
- مصطلحات «المشهور وما به العمل» لا يرجحها النظام؛ يعرض الأقوال فقط.
- جودة OCR/النص المصدر تحدد جودة النتائج.
